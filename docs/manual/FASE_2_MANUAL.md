# Manual de prueba — Fase 2

1. Inicia la aplicación con `npm run dev` y abre `http://localhost:3000`.
2. Selecciona una organización y un periodo con datos Canvas.
3. Entra a **Canvas AS IS**. Verifica que aparecen los nueve bloques.
4. Pulsa **＋ Agregar** en un bloque y completa título, descripción, hipótesis, evidencia y metadatos.
5. Edita el elemento y confirma que el cambio se guarda.
6. Pulsa **Enviar a revisión** y luego **Aprobar versión**. Comprueba que desaparecen los controles de edición directa.
7. Pulsa **Clonar para editar** y confirma que aparece una nueva versión en borrador.
8. En AS IS pulsa **Derivar TO BE** o entra a **Canvas TO BE** y pulsa **Clonar AS IS**.
9. Modifica un elemento TO BE y agrega otro nuevo. AS IS debe permanecer igual.
10. En **Comparación**, verifica las categorías `MODIFICAR`, `CREAR`, `ELIMINAR` y `MANTENER` según los cambios.
11. Crea un escenario desde **＋ Nuevo escenario** y crea una versión TO BE asociada a él.
12. Recarga la aplicación y comprueba que versiones, elementos, estados y escenarios permanecen.

La Fase 3 — Inteligencia Artificial — no forma parte de este manual.
